## 🆘 Troubleshooting

**Button doesn't work?**
→ Try logging into Render first: https://dashboard.render.com
→ Then click the deploy link again

**Build fails?**
→ Check the logs in Render dashboard
→ Common fix: Wait and try again (sometimes builds timeout)

**App won't start?**
→ Make sure disk storage was added (should be automatic)
→ Check environment variables are set
